# ERD Summary

Core entities:
- Identity: `users`, `roles`, `permissions`, `sessions`, `login_attempts`, `user_profiles`
- Economy: `wallets`, `wallet_ledger`, `transactions`, `deposits`, `withdrawals`, `payout_accounts`
- Growth/ads: `campaigns`, `campaign_stats`, `campaign_targets`, `banner_campaigns`, `ad_slots`
- Tasking: `task_types`, `tasks`, `task_submissions`, `proof_uploads`
- Rewards/affiliate: `referral_links`, `referral_events`, `memberships`, `membership_plans`, `subscriptions`, `coupons`
- Gamification: `levels`, `user_levels`, `achievements`, `user_achievements`
- Trust/safety: `fraud_events`, `blacklists`, `audit_logs`, `admin_notes`
- Content/support: `cms_pages`, `blog_posts`, `faq_entries`, `support_tickets`, `ticket_replies`, `notifications`
- Ops/localization: `settings`, `countries`, `languages`, `cron_runs`, `file_uploads`
